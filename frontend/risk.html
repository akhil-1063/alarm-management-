AI Risk Analysis

How this module works. This is an explainable, rule-based early-warning engine (thresholds + persistence + hysteresis + combination patterns). It is not a trained machine-learning model and it does not diagnose disease. Every assessment lists the exact reasons and input readings that produced it. A machine-learning model can be added later behind the same interface (see ml/README.md).
