 ESP32 ↔ laptop connection guide (mobile hotspot)

        
    
          
  1. Enable your phone's mobile hotspot (2.4 GHz — the ESP32 cannot use 5 GHz-only hotspots).
    2. 
          
  2. Connect the laptop to that same hotspot.
    3. 
          
  3. Power the ESP32; it connects to the hotspot using the SSID/password in esp32/config.h.
    4. 
          
  4. Find the laptop's hotspot IPv4 address: open cmd and run ipconfig,
              look under the Wi-Fi adapter for IPv4 Address (e.g. 192.168.43.12).
    5. 
          
  5. Set BACKEND_URL in config.h to
              http://LAPTOP_IP:8080 — never assume localhost works from the ESP32.
    6. 
          
  6. Copy the device UID and device token (from registration above) into the config.
    7. 
          
  7. Flash the firmware, open Serial Monitor at 115200 baud, and watch it connect and post readings.
    8. 
          
  8. The device status below turns online once the first reading arrives.
    9. 
        

        

          
Hotspot isolation: some phones block other clients from reaching the laptop
          (AP/client isolation). If the ESP32 cannot reach the backend:
          
1) check the hotspot settings for “block local network” / “AP isolation” and disable it;
          
2) alternatively use a cheap Wi-Fi router where laptop + ESP32 share the same LAN;
          
3) check Windows Firewall — allow Python on Private networks for TCP port 8080.
